                    Comment lire cet écran

                    1. La situation. 60 personnes sont sur une esplanade pendant une fête. Un danger survient (fumée, annonce, sortie fermée). Il y a trois sorties.
                    2. La carte. Chaque symbole est une personne. Couleur et forme = la sortie qu'elle croit la bonne. Un losange gris = personne qui n'a pas encore choisi. Molette ou boutons pour zoomer ; en 3D, glisser ou touches Q et E pour tourner. La vue 2D reste disponible dans le menu des calques.
                    3. Une personne. Cliquez sur un symbole (ou « Chercher une personne ») pour lire ce qu'elle croit, ce qu'elle a perçu, ce qu'on lui a dit, ce dont elle se souvient et pourquoi elle agit ainsi.
                    4. Le déroulé. La courbe montre les sorties au fil du temps, les traits verticaux les événements du monde. Faites-la glisser (ou flèches du clavier) : carte, fil et fiches reviennent à cet instant.
                    5. Les indicateurs. Ce sont les mesures du protocole scientifique. Cliquez-en un pour lire sa définition et remonter au journal.
                    6. Intervenir. Seulement quand une simulation tourne en direct (uv run maree live). Un run enregistré ne peut pas être modifié.

                    Toutes les données affichées viennent du moteur via WebSocket. Sans moteur, l'écran reste vide : rien n'est inventé. Entre deux ticks, le mouvement des personnes est une interpolation d'affichage ; les positions de référence sont celles du journal. En 3D, les hauteurs sont un choix d'affichage : le moteur travaille sur un plan.
